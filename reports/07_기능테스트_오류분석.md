## 3. 오류 이력

오늘 작업 중 실제로 겪은 오류이다. 현상과 조치는 Jaden의 작업 기록과 셸 기록(`~/.bash_history`)을 기준으로 적었다. 오류 당시의 화면이나 로그 원문은 따로 저장하지 않았다.

| 오류 ID | 현상 | 원인 확인 | 조치 | 재검증 | 결과 |
|---|---|---|---|---|---|
| E-01 | WSL에서 `docker: command not found` | Docker Desktop이 실행되지 않았거나 WSL 통합이 꺼져 있음 | Windows에서 Docker Desktop 실행 | `docker compose ps` | 명령 동작. redis, postgres `Up (healthy)` (`raw/T05_infra.txt`) |
| E-02 | uvicorn 시작 시 `ImportError: no pq wrapper available` | psycopg 3가 쓸 libpq를 찾지 못함 (`psycopg-binary` 미설치) | `pip install "psycopg[binary]>=3.2,<4"` (셸 기록) | `python -c "import psycopg; print(psycopg.pq.__impl__)"` | `binary` (psycopg 3.3.7, psycopg-binary 3.3.7). 서버 정상 시작 ([uvicorn_start.png](evidence/uvicorn_start.png)) |
| E-03 | uvicorn 시작 시 `[Errno 98] address already in use` (8000) | `docker compose up -d --build`로 web 컨테이너가 127.0.0.1:8000 사용 중 | web·worker 컨테이너 중지. 이후 `docker compose up -d redis postgres`만 사용 | `docker compose ps -a`, 8000 포트 확인 | web·worker `Exited (0)`. `.venv` uvicorn이 8000에서 실행 (`raw/T01_health.txt`) |
